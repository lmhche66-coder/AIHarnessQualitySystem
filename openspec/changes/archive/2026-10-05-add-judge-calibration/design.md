# Design

## Context

- 既有各层都建立在确定性判据上；回答质量这类维度没有确定性判据，必须由裁判给分。See proposal.md - Why。
- 平台的既有原则是不调用 LLM：契约、轨迹、任务都靠确定性断言。裁判要把这个原则延续下去——平台提供的是校准机器，不是模型客户端。
- 硬约束：未校准的裁判不得参与门禁，否则门禁的结论无法解释。

## Goals / Non-Goals

**Goals:**

- 裁判可替换，平台零模型依赖。
- 一致率带上不确定度，小样本不给出虚假的精确值。
- 位置与长度两类最常见的偏置可被检出。
- 明确区分「可用于门禁」与「仅供参考」。

**Non-Goals:**

- 不实现具体裁判，不内置任何模型调用。
- 不做逐点评分型裁判，本变更只覆盖成对偏好型，这是偏置研究的标准形态。
- 不做裁判的自动改进或提示词优化。
- 不做多裁判集成与一致性聚类。

## Decisions

### D1 只做成对偏好型裁判

位置偏置与长度偏置的研究都在成对比较上定义：交换 A/B 看偏好是否翻转，看更长的一方是否总赢。逐点评分型没有「位置」这个概念，偏置无法用同一套方法度量。
备选：同时支持逐点评分（两套口径，报告复杂且难以横向比较）。

### D2 置信区间用 Wilson 区间

一致率是比例，样本量通常只有几十条。正态近似的区间在小样本和接近边界时会给出越界或过窄的结果；Wilson 区间在小样本下仍然可用，且不需要引入统计库。
备选：正态近似（小样本下会给出 [1.02, 1.08] 这类不可能的值）；自助法（需要重采样与随机数，结论不再确定）。

### D3 位置偏置用交换重跑度量，而不是抽查

对每条样本都跑正序与逆序两次，比较判定背后的实际偏好是否改变。这样得到的是可复现的比例，而不是抽样估计。
备选：只跑一次并抽查若干条（结论依赖抽样，且无法对单条样本给出解释）。

### D4 长度偏置报告为较长候选的胜出比例

该指标直观、可解释，且能直接与阈值比较。相关系数虽然更「统计」，但对使用者更难解释，且样本量小时不稳定。
备选：报告长度与得分的相关系数（小样本下噪声大，难以设阈值）。

### D5 门禁资格由三条件共同决定，且逐条列出未满足项

一致率不够、位置偏置明显、长度偏置明显，任一成立都不能进门槛。逐条列出未满足项，使用者才知道该改裁判还是该补金标集。
备选：只报一个总分（无法指导改进方向）。

### D6 平台不调用模型，裁判由外部提供

与既有各层一致：平台负责校准机器，模型调用留给使用者。这也让校准过程本身完全可测试——用确定性裁判即可验证全部统计与偏置检测逻辑。
备选：内置模型客户端（引入密钥、网络与成本，且校准逻辑无法离线测试）。

## Risks / Trade-offs

- [金标集规模小时置信区间很宽] → 这是如实反映，不是缺陷；报告强制附带区间，避免误读。
- [单一金标集可能不代表真实分布] → 报告记录样本数，使用者可自行判断代表性。
- [成对形态不覆盖逐点评分需求] → 明确写为非目标；逐点评分可先用成对比较近似。
- [位置翻转率对平局判定不敏感] → 平局在交换后仍是平局，不计入翻转；口径在报告中写明。

## Migration Plan

- 全新能力，无迁移。
- 回滚：删除裁判模块与子命令即可，既有各层不受影响。
