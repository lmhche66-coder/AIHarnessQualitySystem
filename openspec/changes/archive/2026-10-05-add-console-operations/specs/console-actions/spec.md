# Spec Delta

## ADDED Requirements

### Requirement: Gold set authoring and labeling

系统 SHALL 支持在界面上创建金标集并逐条标注，标注结果 MUST 持久化到运行根目录下的金标目录。

#### Scenario: 创建金标集

- **WHEN** 用户提交一份包含配对样本的金标集
- **THEN** 系统以给定名称写入金标目录，并在列表中可见

#### Scenario: 逐条标注

- **WHEN** 用户为某条样本选择偏好
- **THEN** 该样本的标注被写入金标集文件，且进度随之更新

#### Scenario: 查看进度

- **WHEN** 金标集中存在未标注的样本
- **THEN** 列表展示已标注数与总数

#### Scenario: 提交的样本不合法

- **WHEN** 提交的样本缺少标识、提示词或偏好取值非法
- **THEN** 系统以请求错误拒绝，并指明第几条样本

#### Scenario: 标注不存在的金标集

- **WHEN** 用户标注一个不存在的金标集
- **THEN** 系统报错并指明该名称

### Requirement: Trace upload

系统 SHALL 支持在界面上传工具调用审计文件并导入为命名轨迹，接受 JSON 与 CSV 两种形态。

#### Scenario: 导入成功

- **WHEN** 用户上传一份合法的审计文件并给出轨迹名
- **THEN** 系统保存该轨迹，并返回记录数与保真度限制

#### Scenario: 审计内容不合法

- **WHEN** 上传内容为空、缺少必要字段或参数不可解析
- **THEN** 系统以请求错误拒绝，并指明出错记录的位置

#### Scenario: 缺少轨迹名

- **WHEN** 用户未提供轨迹名
- **THEN** 系统以请求错误拒绝，而不是写入一个无名的轨迹

### Requirement: Failure reflow review

系统 SHALL 支持在界面上对一次运行执行失败归因，并让人工选择哪些可回流失败写入候选用例。

#### Scenario: 展示可回流失败

- **WHEN** 用户对一次运行执行归因
- **THEN** 界面逐条展示失败用例、失败判据与是否可回流及其原因

#### Scenario: 写出被选中的候选用例

- **WHEN** 用户勾选若干条已通过复现自证的失败并提交
- **THEN** 系统把对应的候选用例写入运行根目录下的用例目录，并说明写入数量

#### Scenario: 未选中任何候选用例

- **WHEN** 用户没有勾选任何候选用例
- **THEN** 系统不写出文件，并明确说明没有任何内容被写入

#### Scenario: 缺少原始用例定义

- **WHEN** 归因无法找到该运行对应的原始用例定义
- **THEN** 系统报错并说明需要提供用例文件，而不是给出空报告

### Requirement: Run triggering

系统 SHALL 支持从界面用给定的用例文件与工具注册表触发一次同步运行，并返回其运行标识与结果。

#### Scenario: 触发成功

- **WHEN** 用户提供用例文件与工具注册表并触发运行
- **THEN** 系统执行该运行、保存运行记录，并返回运行标识与通过失败计数

#### Scenario: 用例文件不存在

- **WHEN** 用户提供的用例文件不存在
- **THEN** 系统以请求错误拒绝并指明该文件

#### Scenario: 注册表无法载入

- **WHEN** 工具注册表无法载入或未返回注册表
- **THEN** 系统以请求错误拒绝并说明原因

#### Scenario: 运行失败不阻断记录

- **WHEN** 触发的运行中存在失败或出错的用例
- **THEN** 运行记录照常保存并返回结果，而不是以请求错误结束

### Requirement: Operation error contract

每个操作 SHALL 在失败时返回可读原因并指明对象；缺少必需输入、目标不存在与内容不合法 MUST 被区分为不同的请求错误。

#### Scenario: 缺少必需输入

- **WHEN** 请求缺少必需字段
- **THEN** 系统返回请求错误并指明缺失的字段名

#### Scenario: 目标不存在

- **WHEN** 请求指向不存在的运行、金标集或轨迹
- **THEN** 系统返回未找到错误并指明该对象

#### Scenario: 内容不合法

- **WHEN** 请求内容无法解析
- **THEN** 系统返回请求错误并给出可读原因，而不是抛出未处理异常
