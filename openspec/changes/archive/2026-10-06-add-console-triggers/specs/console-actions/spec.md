# Spec Delta

## ADDED Requirements

### Requirement: Gate triggering

系统 SHALL 支持从界面对一次已存储的运行执行门禁判定，并把结论写入结论目录。

#### Scenario: 触发门禁

- **WHEN** 用户选定一次运行并触发门禁
- **THEN** 系统执行判定、写入一条门禁结论，并返回通过与否与失败原因

#### Scenario: 引用不存在的基线

- **WHEN** 用户为门禁指定了一个不存在的基线名
- **THEN** 系统以请求错误拒绝并指明该基线，而不是只按阈值判定

#### Scenario: 未指定基线

- **WHEN** 用户没有指定基线
- **THEN** 系统按阈值判定并在结果中说明未使用基线

### Requirement: Judge calibration triggering

系统 SHALL 支持从界面用指定金标集与判定器执行裁判校准，并把结论写入结论目录。

#### Scenario: 触发校准

- **WHEN** 用户选定金标集与判定器并触发校准
- **THEN** 系统执行校准、写入一条校准结论，并返回一致率、置信区间与偏置指标

#### Scenario: 金标集尚未标注

- **WHEN** 金标集中没有任何已标注样本
- **THEN** 系统以请求错误拒绝并说明需要先完成标注

#### Scenario: 部分样本未标注

- **WHEN** 金标集中只有部分样本已标注
- **THEN** 系统只用已标注样本执行校准，并在结果中说明跳过的数量

#### Scenario: 判定器无法载入

- **WHEN** 指定的判定器工厂无法载入或未返回可调用对象
- **THEN** 系统以请求错误拒绝并说明原因

## MODIFIED Requirements

### Requirement: Run triggering

系统 SHALL 支持从界面触发一次同步运行，覆盖「契约与过程用例」与「端到端任务集」两种模式，并返回其运行标识与结果。

#### Scenario: 触发成功

- **WHEN** 用户提供用例文件与工具注册表并触发运行
- **THEN** 系统执行该运行、保存运行记录，并返回运行标识与通过失败计数

#### Scenario: 触发任务集

- **WHEN** 用户提供任务集文件、环境工厂与 agent 工厂并触发运行
- **THEN** 系统执行任务集、保存运行记录，并返回解决数与通过率

#### Scenario: 用例文件不存在

- **WHEN** 用户提供的用例文件不存在
- **THEN** 系统以请求错误拒绝并指明该文件

#### Scenario: 注册表无法载入

- **WHEN** 工具注册表无法载入或未返回注册表
- **THEN** 系统以请求错误拒绝并说明原因

#### Scenario: 运行失败不阻断记录

- **WHEN** 触发的运行中存在失败或出错的用例
- **THEN** 运行记录照常保存并返回结果，而不是以请求错误结束
